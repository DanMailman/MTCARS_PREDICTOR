# MTCARS Predictor

R/Quarto statistical analysis of the built-in `mtcars` dataset for predicting miles per gallon from vehicle variables.

The analysis conditions variables, studies correlations, compares model candidates, and presents a compact regression-modeling argument in a reproducible Quarto document.

## What It Shows

- Reproducible R/Quarto analysis workflow
- Exploratory data conditioning and correlation analysis
- Linear-model selection and interpretation
- Report-oriented statistical communication
